# Dila Türkmen portfolio — approved color theme

This is a static website. The deployable files are already at the repository root.

## Files

- `index.html` — page structure and content
- `styles.css` — layout, typography, responsive rules, and color theme
- `script.js` — navigation and page interactions
- `favicon.svg` — browser-tab icon
- `Dila-Turkmen-CV.pdf` — downloadable CV

## Deploy with GitHub Pages

Upload all files to the root of your Pages repository, commit them to the publishing branch, and set GitHub Pages to deploy from that branch's root directory.

## Deploy with Vercel

Import the repository as a project. No framework or build command is required; the site is plain HTML, CSS, and JavaScript.
